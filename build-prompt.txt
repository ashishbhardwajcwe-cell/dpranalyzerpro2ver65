NETLIFY FUNCTION 1: auth.js

Purpose: Validate firm access token
Input: token string
Process:
- Query Supabase firms table where access_token matches
- Check is_active equals true
- Check expiry_date is not passed
- Check analyses_remaining is greater than zero
Output JSON: valid true or false, firm_name, analyses_remaining, 
expiry_date, message

NETLIFY FUNCTION 2: analyze.js

Purpose: Run AI analysis with full prompt hidden server-side
Input: token, document_base64, document_name, project_name

Process:
1. Validate token
2. Check analyses_remaining greater than zero
3. Load all IRC reference files from irc-data/ folder 
   using Node.js fs module, read each .md file if it exists
4. Build full prompt combining system message plus IRC content
5. Call Anthropic API
6. Parse JSON response
7. ONLY IF successful: increment analyses_used by one 
   and write to usage_log
8. Return analysis result to frontend
